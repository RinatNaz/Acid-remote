# Acid Remote

A browser step sequencer for hardware drum machines and bass synths over USB MIDI.
Draw drum and bass patterns on screen; the machines play them in sync, and you
shape the sound with their own knobs.

Open it: https://raw.githack.com/RinatNaz/Acid-remote/main/index.html

## Features

- Drum and bass machines side by side, 8 patterns each, switched on the next bar
- Track mode: parts that build up, peak and wind down
- Library of named sessions with file export and import
- Device profiles: recognises TD-3, RD-6, RD-8, RD-9, TR-8S, Volca Beats and Volca Bass
  and remembers the channel and note layout per device
- Tempo from the computer (wheel, arrow keys, tap) or from a machine's MIDI clock
- Installable as an app in Chrome, works offline

## Requirements

Web MIDI: Chrome or Edge on a computer or Android. On iPhone and iPad use a
browser app with Web MIDI support. Machines connect over USB and need no drivers.

Tested with a Behringer TD-3-MO and RD-6. Other profiles use factory note maps.
